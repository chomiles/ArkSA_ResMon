# ArkSA ResMon

[English](README.md) · [한국어](README.ko.md) · [日本語](README.ja.md)

Windows 向けの **ARK: Survival Ascended（ASA）リソースモニター**です。

ARK: Survival Ascended を余裕を持ってプレイするには、**VRAM 12GB 以上のグラフィックスカードを推奨します**。8GB クラスでも動作は可能ですが、グラフィックス設定を適切に調整し、バックグラウンドアプリの使用量を考慮したうえで、ゲーム用の VRAM を十分に確保する必要があります。実際に必要な容量は、設定や描画される環境によって変わります。

MOD、コスメティック、大規模な拠点やメガトライブの環境では、VRAM 使用量が大きく増えることがあります。専用 VRAM が不足して GPU メモリのデータがシステム RAM に移動する状況では、GPU コアの使用率が高くなくてもフレームレートが低下する場合があります。

**ArkSA ResMon は CPU・RAM・GPU・VRAM の使用量を可視化し、測定可能な範囲で ARK と他のアプリの使用量を分けて表示するツールです。** バックグラウンド処理が占有しているリソースや、プレイ中のメモリ逼迫の兆候をひと目で確認できます。

メモリ状態は使用量の変化に基づく推定です。実際のページングイベントやフレームレートを直接測定するものではありません。

## ダウンロードと起動

1. [ARK_Resmon.exe](dist/ARK_Resmon.exe) のページで **Download raw file** ボタンを使ってダウンロードするか、リリースに EXE が添付されている場合はそのファイルを使用してください。
2. ダブルクリックで起動します。インストール、Python、別途 GIF ファイルの用意は不要です。
3. ARK: Survival Ascended を起動すると自動接続します。ゲームを再起動した場合も再接続します。

右上の **KOR / JPN / ENG** で言語を切り替えます。起動時の既定言語は毎回 **英語**です。**最前面に表示**でウィンドウを手前に固定できます。ウィンドウを閉じるか **Esc** を押すと終了します。

## 動作環境

- Windows 10/11 x64、.NET Framework、Windows PowerShell 5.1。
- GPU の測定には Windows GPU パフォーマンスカウンターと NVIDIA ドライバーの `nvidia-smi` を使用します。他社 GPU への対応は限定的です。
- 必要な測定値を取得できない場合、該当項目は **測定不可** と表示されます。

## 表示の見方

- **金色:** ARK の使用量。**青みがかった灰色:** 他のアプリの使用量。空白はアイドル状態または空きメモリです。
- CPU/GPU の割合はデバイス全体を基準にしています。ARK のシステム RAM はプロセスのワーキングセットです。
- **≈** が付いた GPU・VRAM の「その他」は、全体から ARK の使用量を引いた推定値です。共有メモリや測定元・タイミングの違いにより誤差が生じることがあります。
- 大きなメモリ数値は GiB を `GB`、詳細値は MiB を `MB` として表示します。
- メモリ状態は **待機 / 測定準備 / 兆候なし / メモリ逼迫 / スワップの疑い / 測定不可** です。共有 GPU メモリの使用だけでスワップとは断定しません。
