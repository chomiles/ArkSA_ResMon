# Status animations

These 64×64 GIFs are used by the monitor and embedded in the EXE:

- `fun_64x64.gif`: waiting for ARK.
- `cheer_64x64.gif`: running, warming up, or no recent signs of memory pressure.
- `sick_64x64.gif`: memory pressure.
- `dizzy_64x64.gif`: suspected swapping.

An optional `unknown_64x64.gif` can override the fallback for unavailable measurements.
